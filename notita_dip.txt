### Paso 1: Certificados SSL y Configuración de VS Code

Ejecuta en PowerShell:

```powershell
# 1. Crear carpeta .continue si no existe
New-Item -ItemType Directory -Path "$env:USERPROFILE\.continue" -Force

# 2. Exportar certificados de Windows
$certs = Get-ChildItem -Path Cert:\LocalMachine\Root, Cert:\LocalMachine\CA, Cert:\CurrentUser\Root, Cert:\CurrentUser\CA
$pem = foreach ($cert in $certs) {
    "-----BEGIN CERTIFICATE-----`n" + [Convert]::ToBase64String($cert.RawData, 'InsertLineBreaks') + "`n-----END CERTIFICATE-----`n"
}
$pemPath = "$env:USERPROFILE\.continue\certs.pem"
$pem | Out-File -FilePath $pemPath -Encoding ascii
Write-Host "Certificados exportados a: $pemPath"

# 3. Configurar variable de entorno NODE_EXTRA_CA_CERTS
[Environment]::SetEnvironmentVariable("NODE_EXTRA_CA_CERTS", $pemPath, "User")
$env:NODE_EXTRA_CA_CERTS = $pemPath

# 4. Configurar settings.json de VS Code
$settingsPath = "$env:APPDATA\Code\User\settings.json"
if (Test-Path $settingsPath) {
    $json = Get-Content $settingsPath -Raw | ConvertFrom-Json
} else {
    $json = [PSCustomObject]@{}
}
$json | Add-Member -NotePropertyName "http.proxyStrictSSL" -NotePropertyValue $false -Force
$json | ConvertTo-Json -Depth 10 | Set-Content $settingsPath -Encoding utf8
Write-Host "VS Code settings.json actualizado con http.proxyStrictSSL = false"
```

# PARTE 3: Resumen de Errores Resueltos

1. **`unable to get local issuer certificate` (SSL Corporativo):**
   - **Causa:** El proxy de red de la empresa intercepta el tráfico TLS usando certificados de la CA interna que Node.js y Python no traen incluidos por defecto.
   - **Solución:** Exportar la cadena de certificados de Windows a `certs.pem` y vincular `NODE_EXTRA_CA_CERTS`.

2. **Error 400 en `/v1/responses` (Continue):**
   - **Causa:** Continue 2.0 intenta por defecto usar el nuevo endpoint de OpenAI `/v1/responses` cuando ve `gpt-5` en el nombre del modelo. LiteLLM únicamente expone `/v1/chat/completions`.
   - **Solución:** Agregar `useResponsesApi: false` en `config.yaml`.

3. **`Language model unavailable` y selector oculto (Copilot):**
   - **Causa:** VS Code exige que al menos un modelo esté registrado con `isDefault: true`. Si la cuenta de GitHub no tiene un modelo asignado y los BYOK no tienen el flag, VS Code desactiva el menú y rechaza los mensajes.
   - **Solución:** Marcar `isDefault: true` en `TCS: GPT-5.3 Codex` y habilitar `isDefault` en las funciones `kee` y `Dee`.

4. **Error 400 `litellm.UnsupportedParamsError: ['top_p']` (Copilot / LiteLLM):**
   - **Causa:** Copilot Chat envía `top_p` y `temperature: 0.7` en cada petición. El backend de Azure OpenAI y LiteLLM para la familia GPT-5 rechaza estos parámetros con error 400.
   - **Solución:** En `Sh.interceptBody`, eliminar `top_p`, `n` y `temperature` para los modelos GPT-5 antes del envío.
